## Tech Debt and Caveats

- **TEST-01 external blocker.** Upstream testing feed has `Evening_Mist.map` returning 404. Our TEST-03 safety rail held in production across CLI, web, and native paths, so the feature is **safer** than if we had blindly downloaded what was available. When upstream fixes the URL, a rerun would positively demonstrate TEST-01.
- **Venv launcher on user's machine** (exit 103). System Python fallback works. Documented in Phase 1 and 4. Not a sync-engine issue; the fallback chain transparently handles it.
- **`record_maps` has 6 stale rows** for stems no longer in the sync manifest (Chdd_comp, FrostBound_Gifts, Helpless, Never-gonna-give-you-up, Snowy_Structure, Stone_Mountain). Left alone by design — not in current `types/` tree, won't be looked up by sv_map. Repair flag (`--repair-server-column`) is opt-in and only touches rows whose `Map` matches a currently-synced stem.
- **Phases 3 and 4 lack `*-PLAN.md`** files. Retroactive SUMMARY+VERIFICATION+VALIDATION flow was used. Original audit accepted this; not blocking.

## Post-Audit Hardening Summary

After the original 2026-05-13 audit was filed, the user found that maps couldn't be voted in production. Three layered bugs were discovered and fixed:

| Commit | Bug | Fix |
|--------|-----|-----|
| `602ee30` | storage.cfg single-line wrong shape; testingmaps wrote to wrong layout; record_maps.Server used category instead of 'DDNet' | Multi-line per-category storage.cfg; testingmaps now under `maps/` subfolder + migration; hardcoded `Server='DDNet'`; opt-in `--repair-server-column` for stale rows |
| `fca71de` | DDNet's storage.cfg lives at `$CURRENTDIR` (Steam install dir, not `%APPDATA%`); `$USERDIR` not expanded as a prefix per upstream `storage.cpp::AddPath()` source | Absolute paths in storage.cfg; `_resolve_server_storage_cfg()` finds the install dir via WMIC + drive probing |
| `ce3c3e6` | DDNet `MAX_PATHS=16` cap dropped fun/event categories | New `types/_all/maps/` combined hardlink dir; single add_path covers all categories. 4212 → 4261 maps in maplist |
| `0cb23c7` | EXE hardcoded econ password `test123` broke double-click after econ password rotation | Runtime password resolver: env > `ddnet_control.cfg` > running server's autoexec/myServerConfig; never logs the password value |

These fixes did not introduce new requirements — they hardened the existing CFG-* / DB-* / TRIG-03 surface against real-world conditions discovered post-audit.
